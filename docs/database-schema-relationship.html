💡 核心業務流程

  1. 通知發布: 創建通知 → 設置接收人 → 添加問題 → 發布
  2. 通知接收: 用戶收到 → 記錄閱讀狀態 → 查看問題 → 提交答案
  3. 關係鏈: 企業微信部門 → 家長學生關係 → 通知接收對象
